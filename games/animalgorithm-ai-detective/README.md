# 동물고리즘 – AI 탐정

이 폴더는 PLIX 원형을 바탕으로 **초등 AI 수업용으로 수정·개선하는 별도 트랙**입니다.

현재 우선순위는 `../animalgorithm-original-ko/`의 원형 한국어 구현입니다.

기존 v1.0에서 검토했던 항목:

- 명시적 Feature 데이터
- True / False 또는 하이브리드 분류 표현
- Query efficiency
- 규칙 자동 판정
- 난이도
- 협력/경쟁 모드
- 플레이테스트 지표

원형 구현과 검증이 끝난 뒤, 원본의 장점을 잃지 않는 방식으로 v1.1을 재설계합니다.

**주의:** 이 트랙의 규칙을 원형 트랙에 소급 적용하지 않습니다.
