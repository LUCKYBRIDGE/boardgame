# Animal-gorithm: AI Detective Source Pack v1.0

초등 AI 보드게임 **동물고리즘 – AI 탐정** 구현용 소스 문서 묶음입니다.

## 포함 파일

- `Animalgorithm_AI_Detective_Implementation_Spec_v1.0.md`
  - 전체 구현 계획
  - 룰
  - 컴포넌트
  - 디자인 규격
  - 데이터 구조
  - 밸런스/검수 기준

- `animal_cards.schema.json`
  - 동물 카드 JSON Schema

- `secret_rules.schema.json`
  - 비밀 규칙 JSON Schema

- `sample_data.json`
  - 구현 테스트용 샘플 카드/규칙

- `PLAYTEST_CHECKLIST.md`
  - 교실 및 내부 플레이테스트 체크리스트

## 권장 적용 위치

```text
<project-root>/boardgames/animalgorithm-ai-detective/
```

또는 기존 프로젝트 구조에 맞춰 `docs/`, `data/`, `assets/`, `src/` 폴더로 분리해서 사용하십시오.

## 중요한 주의

제공된 MIT 기반 분석 자료의 개념과 활동 구조를 참고했지만, 실제 배포 자산은 별도로 제작하는 것을 전제로 합니다.  
원본 MIT 카드/이미지/레이아웃의 재배포 가능 여부는 이 패키지에서 라이선스를 확정하지 않습니다.
