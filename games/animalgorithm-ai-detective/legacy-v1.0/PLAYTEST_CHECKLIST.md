# 동물고리즘 – AI 탐정 플레이테스트 체크리스트

## A. 세팅
- [ ] 인원: ___명
- [ ] 학년: ___학년
- [ ] 게임 모드: 경쟁 / 협력
- [ ] 사용 규칙 난이도: 1 / 2 / 3
- [ ] Query 토큰 수: ___개

## B. 룰 이해
- [ ] 5분 안에 규칙 설명 완료
- [ ] 학생이 "동물 카드를 넣으면 True/False가 나온다"를 이해함
- [ ] 직접 "날개 있어요?" 같은 질문을 하지 않고 카드 Query를 사용함
- [ ] 규칙 추측과 Query 행동을 구별함

## C. 카드/디자인
- [ ] 동물 이름을 쉽게 읽음
- [ ] Feature 아이콘을 별도 설명 없이 대부분 이해함
- [ ] 다리 수 / 날개 / 서식지 등 핵심 Feature가 그림과 충돌하지 않음
- [ ] True/False 영역이 색 이외의 기호로도 구분됨

## D. 게임성
- [ ] 첫 라운드가 6분 이내
- [ ] 아무 카드나 내는 것이 아니라 정보량이 큰 카드를 찾기 시작함
- [ ] 이미 확인한 카드와 비슷한 카드만 반복해서 내지 않음
- [ ] 규칙이 지나치게 빨리 노출되지 않음
- [ ] Query가 모두 끝나도 규칙을 전혀 추론 못하는 상황이 반복되지 않음

## E. 교육적 행동
- [ ] 학생이 True 카드의 공통점을 찾음
- [ ] 학생이 False 카드의 공통점을 찾음
- [ ] 새 결과를 보고 기존 가설을 수정함
- [ ] "Feature"를 자신의 말로 설명할 수 있음
- [ ] "좋은 Query"를 고른 이유를 말할 수 있음
