# Animal-gorithm Original KO 플레이테스트 기록 기준

`PROJECT DEFAULT`

기록지는 설명문을 길게 넣지 않는다. 학생/교사가 직접 적기 쉽도록 **짧은 항목명 + 넓은 필기 빈칸**을 우선한다.

현재 A4 기록지의 핵심 항목:

- 기본 정보: 날짜 / 학년 / 인원 / 라운드 / 결정자 / 사용 분류 기준
- 진행 확인: 차례 순서 / 동시 위치 예측 / 결정자 힌트 여부 / A4 플레이 영역 사용성
- 플레이 기록: 처음 떠올린 기준 / 시험한 동물 / 선택 이유 / 위치 예측 / 실제 위치 / 가설 변화 / 최종 정답 / 라운드 시간
- 애매했던 동물 / 판정: 자유 기록
- 다음에 바꾸고 싶은 점 / 추가 메모: 넓은 자유 기록 공간

세부 결과와 로그는 GitHub의 플레이테스트 결과 파일에 별도로 보존한다.
