# Animal-gorithm 원형 한국어 규칙 v0.1

> 목표: PLIX 원본의 플레이 루프를 바꾸지 않고 실제 테이블에서 바로 진행할 수 있게 한국어로 정리한다.
> 원본에 없는 세부사항은 반드시 **PROJECT DEFAULT**로 표시한다.

## 기본 정보

- 대상 연령: 12–100
- 인원: 3–6명
- 역할: 1명은 **결정자(Decider)**, 나머지는 추리 플레이어

## 게임 목표

LEFT와 RIGHT에 놓인 동물들을 관찰하여:

- LEFT 동물들의 공통점
- RIGHT 동물들의 공통점
- 두 그룹을 가르는 차이

를 추론하고, 결정자가 정한 **두 비밀 카테고리**를 알아낸다.

## 준비

1. 동물 카드를 준비한다.
2. Category Idea 카드를 사용할 경우 한 장을 선택할 수 있게 준비한다.
3. 한 명을 결정자로 정한다.
4. 결정자는 다른 플레이어에게 보이지 않게 LEFT / RIGHT 카테고리를 정한다.

### PROJECT DEFAULT — 첫 예시 카드

원본 문장은 정확한 시작 카드 수를 정하지 않는다.
원본 도식의 예시처럼 **3장**으로 시작한다.

- LEFT와 RIGHT에 최소 1장씩 있어야 한다.
- 결정자가 3장을 골라 알맞은 쪽에 공개 배치한다.

## 플레이

### 1. 다음 동물을 예측한다

결정자가 아직 분류되지 않은 동물 카드 한 장을 보여준다.

다른 플레이어들은 그 동물이:

- LEFT에 갈지
- RIGHT에 갈지

먼저 예상한다.

예측은 정답 자체가 아니라, 현재까지 관찰한 패턴으로 **새 데이터를 분류해 보는 단계**다.

### 2. 실제 위치를 확인한다

결정자는 자신이 정한 비밀 카테고리에 따라 카드를 LEFT 또는 RIGHT에 놓는다.

플레이어는 자신의 가설과 실제 분류 결과를 비교한다.

### 3. 카테고리를 추측하거나 카드를 추가한다

플레이어는 다음 중 하나를 한다.

**A. 비밀 카테고리 추측**
- LEFT 카테고리와 RIGHT 카테고리를 함께 말한다.
- 맞으면 라운드가 끝난다.

**B. 새 카드 추가**
- 아직 분류되지 않은 동물 카드 하나를 선택해 추가 데이터로 사용한다.
- 카드를 놓기 전에 어느 쪽으로 갈지 예측한다.
- 결정자가 실제 위치를 공개한다.

### PROJECT DEFAULT — 카드 선택 방식

원본은 “add cards”의 구체적인 뽑기 방식을 정하지 않는다.
원형의 정보 탐색 성격을 살리기 위해 **남은 동물 카드를 모두 볼 수 있게 두고, 추가할 카드를 플레이어가 선택**하는 것을 기본값으로 한다.

이 선택은 점수를 얻기 위한 행동이 아니라 “어떤 동물을 확인하면 두 가설을 가장 잘 구별할 수 있을까?”를 생각하게 하기 위한 것이다.

## 라운드 종료

누군가 LEFT와 RIGHT의 비밀 카테고리를 정확히 알아내면 라운드가 끝난다.

원본에는 별도 점수 체계가 제시되어 있지 않으므로 **기본 원형 모드에서는 점수를 사용하지 않는다.**

### PROJECT DEFAULT — 다음 결정자

원본은 “다른 사람이 Decider가 된다”고만 안내한다.
기본 구현에서는 시계 방향으로 다음 사람이 결정자가 된다.

## 원본 Category Idea

1. 포유류 / 포유류가 아님
2. 색이 화려함 / 색이 화려하지 않음
3. 비늘이 있음 / 비늘이 없음
4. 날 수 있음 / 날 수 없음
5. 다리가 2개 / 그 외
6. 알을 낳음 / 알을 낳지 않음
7. 곤충을 먹음 / 곤충을 먹지 않음
8. 직접 만든 카테고리 / 그 반대

## 생각해 보기

- 어떤 카테고리는 왜 쉽게 알아챘는가?
- 어떤 카테고리는 왜 더 어려웠는가?
- 새 동물 카드 하나가 기존 가설을 어떻게 바꾸었는가?
- 여러 후보 중 어떤 동물을 추가하면 가장 많은 정보를 얻을 수 있었는가?

## 원형 모드에서 넣지 않는 것

다음 요소는 개선형 트랙에서 검토하며 원형 모드에는 기본 적용하지 않는다.

- True / False 보드
- Query 토큰
- 규칙 난이도 1/2/3
- AND / OR 논리식 카드
- 카드의 Feature 아이콘 바
- 점수 트랙
- 자동 판정 엔진
