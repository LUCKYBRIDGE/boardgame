# Animal-gorithm Original KO 규칙 v0.2

> 목적: PLIX 원작의 LEFT / RIGHT 분류, 다음 카드 예측, 카테고리 추측 또는 새 카드 추가 구조를 유지한 한국어 종이 프로토타입 규칙.

## SOURCE — 원작에서 확인되는 핵심

1. 한 명이 **결정자(Decider)**가 된다.
2. 결정자는 LEFT와 RIGHT의 **비밀 카테고리**를 정한다.
3. 결정자는 동물 카드를 LEFT / RIGHT에 배치한다.
4. 다른 플레이어들은 **다음 동물이 어느 쪽으로 갈지 예측**한다.
5. 플레이어는 **비밀 카테고리를 추측하거나 새 카드를 추가**할 수 있다.
6. 누군가 비밀 카테고리를 정확히 맞힐 때까지 반복한다.
7. 다음 판에는 다른 사람이 결정자가 된다.

## 준비

- PLIX 동물 카드: 이름 있는 카드 46장
- 빈 동물 카드: 10장(선택)
- Category Idea 카드: 8장
- LEFT / RIGHT 플레이 영역
- 플레이어 3~6명

## PROJECT DEFAULT — 실제 진행을 위한 최소 보완

- 첫 공개 예시는 3장으로 시작하며 LEFT와 RIGHT에 최소 1장씩 둔다.
- 남은 동물 카드는 모두 볼 수 있게 펼쳐 둔다.
- 현재 플레이어는 자신의 차례에 아래 둘 중 하나를 선택한다.
  1. 비밀 카테고리 추측
  2. 새 동물 카드 추가
- 새 카드를 추가할 때는 **배치 전에 LEFT / RIGHT를 먼저 예측**한다.
- 결정자는 카드를 정해 둔 기준에 따라 한쪽에 배치한다.
- 오답 추측에 별도 페널티는 없다.
- 점수는 사용하지 않는다.
- 다음 결정자는 시계 방향으로 바꾼다.
- 표현이 달라도 의미가 같으면 정답으로 인정한다.

## PROJECT DEFAULT — 사용자 정의 카테고리

원본 Category Idea의 대부분은 X / not-X 구조다.
사용자 정의 카테고리도 기본적으로 **X / X가 아님**처럼 모든 동물이 정확히 한쪽에 들어가게 만든다.

예:
- 물에서 주로 생활함 / 그렇지 않음
- 사람보다 큼 / 그렇지 않음

`귀여움`, `무서움`처럼 사람마다 판정이 크게 달라지는 카테고리는 원작에서 명시적으로 금지되지 않지만, 교실 프로토타입에서는 가급적 피한다.

## 라운드 종료

LEFT와 RIGHT의 비밀 카테고리를 정확히 맞힌 플레이어가 나오면 라운드를 끝낸다.

원작 충실판에서는 점수 계산을 하지 않는다.
