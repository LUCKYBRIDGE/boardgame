# Animal-gorithm Original KO 규칙 v0.3

> 목표: PLIX 원작의 LEFT / RIGHT 분류, 다음 카드 예측, 비밀 카테고리 추측 또는 새 카드 추가 구조를 유지하면서 실제 교실에서 혼동 없이 진행할 수 있도록 세부 운영 규칙을 보완한다.
>
> 표기:
> - `SOURCE`: PLIX 원본에서 직접 확인되는 구조
> - `PROJECT DEFAULT`: 원본에 세부 설명이 없어 실제 플레이를 위해 정한 기본값

## 1. 게임의 핵심

### SOURCE

1. 한 명이 **결정자(Decider)**가 된다.
2. 결정자는 LEFT와 RIGHT에 적용되는 **비밀 카테고리**를 정한다.
3. 결정자는 동물 카드를 LEFT / RIGHT에 배치한다.
4. 다른 플레이어들은 **다음 동물 카드가 어느 쪽에 들어갈지 예측**한다.
5. 플레이어는 **비밀 카테고리를 추측하거나 새 카드를 추가**한다.
6. 누군가 비밀 카테고리를 정확히 맞힐 때까지 반복한다.
7. 다음 판에는 다른 사람이 결정자가 된다.

## 2. 무엇을 누가 볼 수 있는가

### 모두에게 공개
- 모든 동물 카드의 그림과 이름
- 이미 LEFT / RIGHT에 분류된 동물 카드
- 현재 시험할 새 동물 카드
- LEFT / RIGHT 플레이 영역

### 결정자만 봐야 하는 것
- 이번 라운드의 **비밀 카테고리 카드**
- 직접 만든 카테고리라면 그 내용을 적은 카드/메모
- 애매한 동물을 어떻게 판정할지 미리 정한 개인 메모

### PROJECT DEFAULT — 비밀 유지
- 결정자는 카테고리를 정한 뒤 카드를 뒤집어 놓거나 종이/책 아래에 가린다.
- 직접 만든 카테고리는 첫 동물 카드를 놓기 전에 두 범주를 모두 적어 둔다.
- 라운드 도중 비밀 카테고리를 바꾸면 안 된다.

## 3. 준비

1. 3~6명이 앉는다.
2. LEFT / RIGHT 플레이 영역을 중앙에 놓는다.
3. 동물 카드를 모두 볼 수 있게 펼친다. (`PROJECT DEFAULT`)
4. 한 명을 결정자로 정한다.
5. 결정자는 기존 Category Idea 카드 또는 직접 만든 카테고리로 비밀 카테고리를 정한다.
6. 비밀 카테고리는 다른 플레이어에게 보이지 않게 가린다.
7. 결정자는 예시 동물 3장을 골라 LEFT와 RIGHT에 놓는다. (`PROJECT DEFAULT`)
   - 양쪽에 최소 1장은 있어야 한다.

## 4. 한 차례의 자세한 진행

### A. 행동 선택
현재 플레이어는 둘 중 하나를 선택한다.
1. **비밀 카테고리를 추측한다.**
2. **새 동물 카드를 시험한다.**

### B-1. 카테고리를 추측할 때
- LEFT와 RIGHT의 기준을 한 쌍으로 말한다.
- 결정자는 정답 여부만 알려 준다.

`PROJECT DEFAULT`
- 오답일 때 어느 쪽이 맞았는지 부분 힌트를 주지 않는다.
- 오답 페널티와 점수는 사용하지 않는다.
- 한 플레이어는 자기 차례에 한 번만 정답을 말한다.

### B-2. 새 동물을 시험할 때
1. 아직 분류되지 않은 동물 카드 1장을 고른다.
2. LEFT나 RIGHT에 바로 놓지 않고 가운데 **NEXT / 다음 카드** 위치에 둔다.
3. 결정자가 손을 대기 전에 플레이어들이 어느 쪽으로 갈지 예측한다.
4. 예측이 끝난 뒤 결정자가 실제 카드를 LEFT 또는 RIGHT로 이동한다.
5. 모든 플레이어는 새 정보를 보고 자신의 가설을 수정한다.
6. 다음 플레이어에게 차례를 넘긴다.

## 5. 결정자가 특히 조심할 것
- 카드를 보는 순간 한쪽을 쳐다보지 않는다.
- 어려운 카드에서만 오래 고민하지 않는다.
- 고개 끄덕임, 웃음, "좋은 카드 골랐네" 같은 반응을 줄인다.
- 플레이어의 가설에 맞다/틀리다 식의 추가 코멘트를 하지 않는다.
- 라운드 시작 전에 기준을 확정하고 중간에 예외를 만들지 않는다.
- "날개가 있으면 LEFT예요?" 같은 직접 질문에는 답하지 않고 "확인하고 싶은 동물 카드를 골라 시험해 보세요."라고 안내한다.

## 6. 플레이어가 조심할 것
- 이미 분류된 동물 카드를 임의로 옮기지 않는다.
- 비밀 카테고리 카드나 결정자의 메모를 들춰보지 않는다.
- 결정자가 카드를 놓기 전에 먼저 예측한다.
- 동물 이름보다 두 그룹의 공통점과 차이를 본다.
- 비슷한 카드만 계속 고르기보다 가설을 구별할 수 있는 동물을 고른다.

## 7. 직접 만든 카테고리

원본에는 빈 Category Idea 카드가 있으며 `X / Not X` 형태다.

### 원본형 권장
- LEFT: X
- RIGHT: X가 아님

### PROJECT DEFAULT — 두 칸 직접 작성형
한국어 표현과 수업 활용을 쉽게 하기 위해 LEFT와 RIGHT를 각각 직접 쓰는 빈 카드도 추가한다.

조건:
- 두 범주가 겹치지 않아야 한다.
- 시험할 동물이 어느 쪽에도 속하지 않는 상황을 피한다.
- 너무 주관적인 기준은 가능하면 피한다.
- 카드 그림의 배경색이나 인쇄 모양 같은 우연한 시각 요소를 기준으로 삼지 않는다.

## 8. 애매한 판정이 생겼을 때

원본 Category Idea의 `Colorful`이나 `Eats bugs`처럼 해석 차이가 생길 수 있는 항목이 있다.

`PROJECT DEFAULT`
1. 결정자는 라운드 전에 애매한 동물의 판정을 정한다.
2. 라운드 도중 논쟁이 생겨도 비밀 카테고리를 공개하지 않는다.
3. 결정자의 기존 판정을 그대로 적용하고 라운드를 끝까지 진행한다.
4. 라운드가 끝난 뒤 왜 애매했는지 함께 검토한다.
5. 같은 문제가 반복되면 해당 카테고리의 교실 사용 여부를 기록한다.

## 9. 라운드 종료

비밀 카테고리 한 쌍을 정확히 맞힌 플레이어가 나오면 라운드를 끝낸다.

`PROJECT DEFAULT`
- 의미가 같은 표현이면 정답으로 인정한다.
- 기본 원작판에서는 점수를 계산하지 않는다.
- 다음 결정자는 시계 방향으로 바꾼다.

## 10. 원작판에서 기본 적용하지 않는 것
- True / False 보드
- Query 토큰
- Feature 아이콘
- AND / OR 난이도
- 점수 트랙
- 자동 판정
