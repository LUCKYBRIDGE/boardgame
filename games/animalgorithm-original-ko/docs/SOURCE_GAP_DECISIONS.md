# Source Gap Decisions

PLIX 원본을 가능한 한 그대로 구현하되, 실제 플레이에 필요한데 원본에서 정확히 정하지 않은 부분만 기록한다.

## 직접 만든 카테고리

원본 빈 카드는 기본적으로 `X / Not X` 구조다.
한국어 프로토타입에는 이 원본형을 유지하면서, 실제 수업에서 표현하기 쉽도록 왼쪽 / 오른쪽을 각각 적는 추가 양식도 제공한다.

자유 작성형은 다음을 만족해야 한다.

- 두 범주가 겹치지 않음
- 사용할 동물이 어느 쪽에도 속하지 않는 문제를 피함
- 가능하면 판정이 일관됨
- 카드 배경, 인쇄 모양 등 우연한 시각 요소를 기준으로 삼지 않음

## 의도적으로 해결하지 않은 문제

### “Colorful”의 주관성
원본 Category Idea에 실제로 포함되어 있으므로 원형판에서는 유지한다.
객관적 Feature만 쓰도록 바꾸는 것은 개선형 트랙의 작업이다.

### 생물 지식 의존
원형 카드는 Feature 설명을 제공하지 않는다.
따라서 원형판에서는 이 특성을 보존한다. 초등 수업용 개선판에서는 별도로 해결한다.

### 애매한 판정
라운드 중에는 결정자의 사전 판정을 유지하고, 라운드가 끝난 뒤 플레이테스트 기록에서 문제를 검토한다.
