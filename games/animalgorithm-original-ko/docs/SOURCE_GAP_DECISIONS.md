# Source Gap Decisions

PLIX 원본을 가능한 한 그대로 구현하되, 실제 플레이에 필요한데 원본에서 정확히 정하지 않은 부분만 기록한다.

| 항목 | PLIX에서 확인되는 내용 | PROJECT DEFAULT | 이유 |
|---|---|---|---|
| 시작 카드 수 | 결정자가 LEFT와 RIGHT에 카드를 배치함 | 3장, 양쪽 최소 1장 | 원본 도식이 3장의 예시를 보여 주며 최소한의 추론 단서를 제공함 |
| 남은 카드의 공개 여부 | 명시 없음 | 모두 공개 | 플레이어가 “add cards”에서 정보 가치가 높은 동물을 선택할 수 있게 함 |
| 추가 카드 선택자 | 플레이어가 cards를 add할 수 있음 | 현재 플레이어가 선택 | 원본의 능동적 데이터 추가를 구현 가능하게 함 |
| 예측 방식 | 다음 카드가 어느 쪽인지 guess | 말하기 또는 LEFT/RIGHT 손짓 | 별도 컴포넌트를 늘리지 않음 |
| 오답 추측 페널티 | 명시 없음 | 없음 | 원본에 없는 경쟁 규칙을 추가하지 않음 |
| 점수 | 명시 없음 | 없음 | 원형 라운드 구조 보존 |
| 다음 Decider | 다른 사람이 맡음 | 시계 방향 | 진행 충돌 방지 |
| 정답 표현 | secret categories를 맞힘 | 의미가 같으면 정답 인정 | 번역/동의어 차이로 인한 불필요한 오답 방지 |

## 의도적으로 해결하지 않은 문제

### “Colorful”의 주관성
원본 Category Idea에 실제로 포함되어 있으므로 원형판에서는 유지한다.
객관적 Feature만 쓰도록 바꾸는 것은 개선형 트랙의 작업이다.

### 생물 지식 의존
원형 카드는 Feature 설명을 제공하지 않는다.
따라서 원형판에서는 이 특성을 보존한다. 초등 수업용 개선판에서는 별도로 해결한다.

### 서로 겹치는 카테고리
원본 예시는 대부분 상호 보완적인 쌍이다. 사용자 정의 카테고리는 모든 카드가 어느 한쪽에 확실히 들어가도록 만드는 것을 권장하지만, 이는 원본에 명시된 문장이 아니라 운영상 기본 원칙이다.
