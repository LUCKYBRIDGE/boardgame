# Animal-gorithm Original KO 종이 프로토타입 구성 명세

이 문서는 현재 인쇄 프로토타입의 고정 제작 기준이다. 같은 역할의 버전 문서를 늘리지 않고 이 파일을 갱신한다.

## 1. 목표

PLIX 원작의 핵심 플레이 구조와 원본 동물 그림을 유지하면서, 한국어로 바로 출력·재단·플레이테스트할 수 있는 한 세트를 만든다.

## 2. 동물 카드

`SOURCE`

- 이름 있는 동물 카드 46장
- 빈 동물 카드 10장
- PLIX 원본 동물 그림과 카드의 PLIX 표시는 유지한다.

`PROJECT DEFAULT`

- 동물명은 **한국어를 크고 굵게 1차 표기**한다.
- 원래 영문 동물명은 **작은 2차 표기**로 남긴다.
- 이유: 초등학생의 즉시 읽기성을 확보하면서 원본 카드와의 대응 관계도 유지한다.
- 인쇄 시트: A4 가로, 4열 × 2행.
- 카드 크기: 약 64 × 99 mm. 원본 카드 비율을 유지한다.
- 카드 사이에는 재단선을 둔다.

## 3. 분류 기준 카드

`SOURCE`

원본 8종을 한국어 카드로 제작한다.

1. 포유류 / 포유류가 아님
2. 색이 화려함 / 색이 화려하지 않음
3. 비늘이 있음 / 비늘이 없음
4. 날 수 있음 / 날 수 없음
5. 다리가 2개 / 그 외
6. 알을 낳음 / 알을 낳지 않음
7. 곤충을 먹음 / 곤충을 먹지 않음
8. X / X가 아님 직접 작성형

8번은 원본의 작은 밑줄을 그대로 복제하지 않고 논리 구조는 유지하면서 손글씨 공간을 크게 만든다.

## 4. 추가 직접 작성 분류 기준 카드

현재 세트에는 8장을 추가한다.

- `PROJECT DEFAULT` 원본형 추가 사본 4장
  - 형식은 PLIX의 `X / X가 아님`을 유지
  - 왼쪽: X 직접 작성
  - 오른쪽: X가 아님
  - 큰 손글씨 박스 제공

- `PROJECT DEFAULT` 왼쪽 / 오른쪽 자유 작성형 4장
  - 왼쪽과 오른쪽을 각각 직접 작성
  - 두 범주가 겹치지 않고, 사용할 동물이 어느 쪽에도 속하지 않는 문제가 없게 작성

반복 사용 시 카드 슬리브 또는 코팅 후 수성 보드마카 사용은 `PROPOSAL`이다.

## 5. 플레이 영역

`PROJECT DEFAULT`

- **기본 인쇄 규격은 A4 가로 1장**이다.
- 왼쪽 / 다음 카드 / 오른쪽 세 영역을 한 페이지에 배치한다.
- 다음 카드에는 선택한 새 동물을 먼저 놓는다.
- 추리 플레이어 모두의 왼쪽 / 오른쪽 예측이 끝난 뒤 결정자가 실제 위치로 이동한다.
- 더 큰 판이 필요하면 이 A4 플레이 영역 페이지만 A3로 약 141% 확대 복사한다.

## 6. 규칙 및 플레이테스트 자료

인쇄 프로토타입에 다음을 포함한다.

- 상세 규칙 3쪽
  - 4명 기준 역할과 차례
  - 개인 차례 행동 선택과 전체 동시 위치 예측 구분
- SOURCE / PROJECT DEFAULT 구분
- 결정자 비밀정보·비언어 힌트 주의사항
- 직접 질문 처리
- 애매한 판정 처리
- 플레이테스트 기록지 1쪽

## 7. 현재 출력물

생성 파일명:

`Animalgorithm_Original_KO_Print_Prototype.pdf`

구성:

1. 표지/인쇄 안내
2. 동물 카드 7시트 = 56장
3. 분류 기준 카드 1시트 = 8장
4. 직접 작성 분류 기준 카드 1시트 = 8장
5. A4 플레이 영역 1쪽
6. 상세 규칙 3쪽
7. 플레이테스트 기록지 1쪽

총 15페이지이며 **모든 페이지의 용지 규격은 A4**이다. 카드/플레이 영역은 가로, 표지/규칙/기록지는 세로다.

## 8. 재생성 방법

빌드 스크립트:

`scripts/build-print-prototype.py`

예:

```bash
python scripts/build-print-prototype.py \
  --deck-pdf /path/to/plix-deck-animal-database.pdf \
  --out ./output/Animalgorithm_Original_KO_Print_Prototype.pdf
```

필요 Python 패키지:

```bash
pip install reportlab pymupdf pillow
```

한국어 TrueType 글꼴이 필요하다. 기본적으로 NanumGothic 또는 Windows의 맑은 고딕을 찾으며, 필요하면 다음 환경변수로 지정한다.

- `ANIMALGORITHM_KO_FONT_REGULAR`
- `ANIMALGORITHM_KO_FONT_BOLD`

## 9. 원본 자산 처리

PLIX 동물 카드 PDF는 빌드 시 외부 입력으로 받는다. 원본 이미지가 포함된 생성 PDF를 저장소에 상시 커밋하지 않는다.

외부 배포/판매 전에 원본 이미지와 카드 디자인의 개별 라이선스 허용 범위를 다시 확인한다.
