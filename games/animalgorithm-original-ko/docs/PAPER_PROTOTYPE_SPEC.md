# Animal-gorithm Original KO 종이 프로토타입 구성 명세 v0.3

## 이미지 사용 방향

원작 충실 한국어판에서는 **PLIX 원본 동물 카드의 동물 이미지를 그대로 사용하는 방향**으로 프로토타입을 진행한다.

- 동물 그림: 원본 그대로
- 한국어판에서 변경: 동물명, 한국어 안내, 자체 플레이 영역/규칙서
- 외부 배포/판매용 최종판: 원본 자산의 적용 라이선스를 다시 확인한 뒤 결정

## 구성

- PLIX 이름 있는 동물 카드 46장
- PLIX 빈 동물 카드 10장
- 원본 Category Idea 8종 한국어판
- 추가 직접 작성 Category 카드 8장
  - 원본형(X / X가 아님) 4장
  - LEFT / RIGHT 자유 작성형 4장
- 한국어 동물명 라벨 46개
- LEFT / NEXT / RIGHT 플레이 영역
- 상세 규칙 및 주의사항
- 원작판 플레이테스트 기록지

## 직접 작성 카드

- LEFT / RIGHT 영역을 명확히 분리
- 작은 밑줄 대신 손글씨를 충분히 쓸 수 있는 큰 빈 박스 사용
- 작성 후 게임 중 다른 플레이어에게 보이지 않게 뒤집거나 가림
- 반복 사용 시 카드 슬리브 + 수성 보드마카 또는 코팅 활용 권장
