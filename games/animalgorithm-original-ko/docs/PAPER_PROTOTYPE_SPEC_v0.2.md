# Animal-gorithm Original KO 종이 프로토타입 구성 명세 v0.2

## 목적

원본 동물 그림을 새로 복제하지 않고도 한국어 수업 플레이테스트를 시작할 수 있는 최소 구성이다.

## 구성

1. PLIX 원본 동물 카드 PDF
   - 동물 그림은 원본 PDF를 별도 출력하여 사용
2. 한국어 이름 라벨 46개
   - 원본 카드의 영어 이름 위 또는 아래에 부착 가능
3. Category Idea 한국어 카드 8장
4. LEFT / RIGHT A4 플레이 영역 1장
5. 한국어 빠른 규칙 1장
6. 결정자 기록 / 플레이테스트 기록 1장

## 왜 동물 그림을 새로 넣지 않는가

현재 단계에서는 원작 카드 이미지/레이아웃의 외부 재배포 범위를 확정하지 않았다.
따라서 프로젝트에서 만든 프로토타입 PDF에는 원본 동물 그림을 포함하지 않는다.

실제 플레이 시:
- 사용자가 보유한 PLIX 원본 동물 카드 자료를 별도 출력
- 한국어 라벨을 붙여 사용

이 방식은 원작의 카드 데이터셋을 그대로 활용하면서 한국어 진행을 먼저 검증하기 위한 개발용 프로토타입이다.

## 인쇄

- A4, 100% 실제 크기
- '페이지에 맞추기' 확대/축소 비활성 권장
- 라벨은 일반 용지로 출력 후 잘라 붙여도 됨
- Category Idea 카드는 두꺼운 용지 또는 슬리브 사용 권장

## 다음 검증 항목

- 46장을 모두 펼쳤을 때 선택이 지나치게 느리지 않은가
- 시작 예시 3장이 충분한가
- Category Idea 카드의 한국어 표현이 학생에게 명확한가
- '색이 화려함', '곤충을 먹음'에서 분쟁이 얼마나 발생하는가
- 카테고리 추측과 새 카드 추가 중 실제로 어떤 행동이 더 많이 선택되는가
