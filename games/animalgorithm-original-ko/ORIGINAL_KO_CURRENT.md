# 6. 준비

1. 왼쪽 / 다음 카드 / 오른쪽 플레이 영역을 중앙에 놓는다.
2. 동물 카드를 모두 볼 수 있게 펼친다. `PROJECT DEFAULT`
3. 한 명이 결정자가 된다.
4. 결정자는:
   - 기존 Category Idea 카드 1장을 선택하거나
   - 직접 만든 카테고리를 적는다.
5. 카테고리를 다른 플레이어에게 보이지 않게 가린다.
6. `PROJECT DEFAULT`로 예시 동물 3장을 왼쪽 / 오른쪽에 놓는다.
   - 양쪽에 최소 1장씩 둔다.
   - 가능하면 정답이 즉시 드러나는 조합은 피한다.

# 7. 역할과 차례 운영

`SOURCE`

- 한 라운드에는 1명의 결정자와 나머지 추리 플레이어가 참여한다.
- 추리 플레이어들은 다음 동물 카드가 어느 쪽으로 갈지 예측한다.
- 플레이어는 비밀 분류 기준을 추측하거나 새 동물 카드를 추가한다.
- 누군가 비밀 분류 기준을 맞힐 때까지 반복한다.

PLIX 원본은 개인 차례의 정확한 순서, 공식 추측자를 한 명으로 제한하는지, 위치 예측을 동시에 공개하는지까지는 정하지 않는다.

`PROJECT DEFAULT`

## 4명이 플레이할 때

- 결정자 1명 + 추리 플레이어 3명으로 역할을 나눈다.
- 결정자는 비밀 분류 기준을 정하고 시작 동물을 배치하며, 시험 결과와 정답 여부를 판정한다.
- 결정자에게는 별도의 개인 행동 차례가 없다.
- 추리 플레이어 3명은 결정자의 왼쪽 사람부터 시작해 시계 방향으로 개인 차례를 진행한다.
  - 예: A → B → C → A → B → C …

## 현재 차례의 추리 플레이어가 하는 일

현재 차례 플레이어는 다음 둘 중 하나를 선택한다.

1. **비밀 분류 기준 추측**
   - 현재 차례 플레이어만 공식 추측을 한 쌍으로 말한다.
   - 오답이면 결정자는 "아직 정답이 아님" 정도만 말하고 다음 사람 차례로 넘어간다.

2. **새 동물 시험**
   - 현재 차례 플레이어가 아직 분류되지 않은 동물 1장을 고른다.
   - 그 카드를 `다음 카드` 위치에 놓는다.
   - **추리 플레이어 전원이** 결과를 보기 전에 각자 왼쪽 / 오른쪽 위치를 예측한다.
   - 예측은 말하기, 손가락 가리키기 등으로 동시에 공개한다.
   - 모든 예측이 끝난 뒤 결정자가 카드를 실제 위치로 이동한다.
   - 모두가 결과를 보고 가설을 수정한 뒤 다음 추리 플레이어 차례로 넘어간다.

따라서 이 게임은:

> **행동 선택은 개인 차례로 진행하고, 새 카드의 위치 예측은 추리 플레이어 모두가 동시에 참여한다.**

## 라운드 교대

- 누군가 비밀 분류 기준 한 쌍을 맞히면 즉시 라운드가 끝난다.
- 다음 라운드의 결정자는 현재 결정자의 왼쪽(시계 방향 다음 사람)이 맡는다.
- 새 결정자의 왼쪽 추리 플레이어부터 다시 첫 개인 차례를 시작한다.

---

# 8. 한 차례 진행

현재 차례의 추리 플레이어는 둘 중 하나를 선택한다.

## A. 비밀 카테고리 추측

왼쪽과 오른쪽의 기준을 한 쌍으로 말한다.

예:
- "왼쪽은 날 수 있는 동물, 오른쪽은 날 수 없는 동물."

정답이면 라운드를 끝낸다.

`PROJECT DEFAULT`
- 오답 페널티 없음
- 부분 힌트 없음
- 결정자는 "정답" 또는 "아직 정답이 아님" 정도만 말한다.

## B. 새 동물 시험

1. 아직 분류되지 않은 동물 1장을 고른다.
2. 바로 왼쪽 / 오른쪽에 놓지 않고 다음 카드 위치에 둔다.
3. 결정자가 움직이기 전에 추리 플레이어 모두가 왼쪽 / 오른쪽을 동시에 예측한다. `PROJECT DEFAULT`
4. 예측이 끝나면 결정자가 실제 위치로 이동한다.
5. 플레이어는 새 결과를 보고 가설을 수정한다.
6. 시계 방향의 다음 추리 플레이어 차례가 된다. `PROJECT DEFAULT`

# 9. 직접 질문 처리

플레이어가 다음처럼 묻더라도 결정자는 답하지 않는다.

- "날개가 있으면 왼쪽이에요?"
- "포유류예요?"
- "물에 살면 오른쪽이에요?"

대신:

> "확인하고 싶은 동물 카드를 골라 시험해 보세요."

라고 안내한다.

# 10. 결정자 주의사항

- 비밀 카테고리 카드를 다른 사람이 보지 못하게 한다.
- 라운드 중 기준을 변경하지 않는다.
- 특정 동물만 예외로 만들지 않는다.
- 카드 배치 전에 플레이어 예측이 끝났는지 확인한다.
- 오답 가설에 부분 힌트를 주지 않는다.
- 표정, 시선, 손짓, 망설임을 최소화한다.
- "좋은 카드 골랐네", "거의 맞았어" 같은 말을 하지 않는다.
- 직접 예/아니오 질문에 답하지 않는다.

---

# 11. 플레이어 주의사항

- 비밀 카테고리 카드나 결정자 메모를 보지 않는다.
- 이미 분류된 카드를 옮기지 않는다.
- 결과를 보기 전에 먼저 예측한다.
- 동물 이름 맞히기가 아니라 두 그룹의 공통점과 차이를 본다.
- 비슷한 카드만 반복하기보다 가설을 구별할 동물을 찾는다.

# 16. 이미지와 카드 제작

현재 원작판 프로토타입:

`PROJECT DEFAULT` 학생용 표기 원칙:

- `LEFT` → **왼쪽**
- `NEXT` → **다음 카드**
- `RIGHT` → **오른쪽**
- `Decider` → **결정자**
- 학생용 인쇄물에서는 한국어를 우선 표기하고, 영문 원어는 출처 대응이 필요한 문서에서만 보조로 사용한다.

- 동물 이미지: PLIX 원본 그대로 활용
- 동물 이름: `PROJECT DEFAULT`로 **한국어 대형 + 영문 원명 소형 병기**
  - 한국어를 1차 정보로 읽게 한다.
  - 영문은 PLIX 원본 카드 대응 및 교사용 보조 정보로만 남긴다.
- Category Idea: 한국어판 자체 제작
- 직접 작성 Category 카드: 큰 빈칸 확보
- 플레이 영역: 왼쪽 / 다음 카드 / 오른쪽 자체 제작
- 인쇄 기준: `PROJECT DEFAULT`로 **전체 프로토타입 A4 기준**
  - 카드 시트와 플레이 영역: A4 가로
  - 규칙서와 플레이테스트 기록지: A4 세로
  - 플레이테스트 기록지는 줄글 설명을 최소화하고 짧은 항목명과 넓은 필기 공간 중심으로 구성
  - 더 큰 플레이 영역이 필요하면 A4 플레이 영역을 A3로 약 141% 확대 복사

외부 배포/판매 전에는 원본 이미지/카드 디자인 라이선스를 다시 확인한다.

# 17. 현재 검증할 것

- 예시 카드 3장이 적절한가
- 46장 전체 공개가 선택에 도움이 되는가
- 다음 카드 단계가 예측을 명확하게 만드는가
- 오답 페널티가 없어도 무작정 추측하지 않는가
- `Colorful`, `Eats bugs`에서 판정 분쟁이 얼마나 생기는가
- 플레이어가 정보 가치가 높은 동물을 고르기 시작하는가
- 개인 차례 + 모두 동시 위치 예측 구조가 4인 플레이에서 명확한가
- 결정자가 별도 개인 차례 없이 판정 역할만 맡는 방식이 자연스러운가
- A4 플레이 영역이 실제 카드 이동과 테이블 배치에 충분한가
- 한 라운드 시간이 교실 수업에 적절한가
