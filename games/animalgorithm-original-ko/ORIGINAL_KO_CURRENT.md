# Animal-gorithm Original KO — CURRENT
## 원작 충실 한국어판 현재 규칙 및 제작 기준

> 이 파일은 Original KO 트랙의 최신 실행 기준이다.
> 앞으로 규칙이 바뀌면 새 버전 파일을 추가하지 않고 이 파일을 갱신한다.

## 1. 기본 정보

`SOURCE`

- 원작 안내 연령: 12–100
- 인원: 3–6명
- 역할: 1명 Decider, 나머지 추리 플레이어

## 2. 게임 목표

LEFT와 RIGHT에 놓인 동물들을 비교해:

- LEFT의 공통점
- RIGHT의 공통점
- 두 그룹의 차이

를 추론하고 Decider가 정한 비밀 카테고리를 알아낸다.

## 5. 무엇을 누가 보는가

### 모두에게 공개
- 모든 동물 카드
- 이미 LEFT / RIGHT에 분류된 카드
- 현재 시험할 NEXT 카드
- LEFT / NEXT / RIGHT 플레이 영역

### Decider만 확인
- 비밀 Category Idea 카드
- 직접 만든 카테고리 내용
- 필요한 경우 애매한 동물의 사전 판정 메모

`PROJECT DEFAULT`

비밀 카테고리는 뒤집거나 가리고, 첫 동물 배치 전에 확정한다.
라운드 도중 바꾸지 않는다.

## 6. 준비

1. LEFT / NEXT / RIGHT 플레이 영역을 중앙에 놓는다.
2. 동물 카드를 모두 볼 수 있게 펼친다. `PROJECT DEFAULT`
3. 한 명이 Decider가 된다.
4. Decider는 기존 Category Idea 카드 또는 직접 만든 카테고리를 정한다.
5. 카테고리를 다른 플레이어에게 보이지 않게 가린다.
6. `PROJECT DEFAULT`로 예시 동물 3장을 LEFT / RIGHT에 놓는다.
   - 양쪽에 최소 1장씩 둔다.
   - 가능하면 정답이 즉시 드러나는 조합은 피한다.

## 7. 한 차례 진행

현재 플레이어는 둘 중 하나를 선택한다.

### A. 비밀 카테고리 추측
LEFT와 RIGHT의 기준을 한 쌍으로 말한다.

`PROJECT DEFAULT`
- 오답 페널티 없음
- 부분 힌트 없음
- Decider는 정답 또는 아직 정답이 아님 정도만 말한다.

### B. 새 동물 시험
1. 아직 분류되지 않은 동물 1장을 고른다.
2. 바로 LEFT / RIGHT에 놓지 않고 NEXT 위치에 둔다.
3. Decider가 움직이기 전에 플레이어들이 LEFT / RIGHT를 예측한다.
4. 예측이 끝나면 Decider가 실제 위치로 이동한다.
5. 플레이어는 새 결과를 보고 가설을 수정한다.
6. 다음 플레이어의 차례가 된다.

## 8. 직접 질문 처리

플레이어가 "날개가 있으면 LEFT예요?", "포유류예요?"처럼 물어도 Decider는 답하지 않는다.

대신:

> 확인하고 싶은 동물 카드를 골라 시험해 보세요.

라고 안내한다.

## 9. Decider 주의사항

- 비밀 카테고리 카드를 다른 사람이 보지 못하게 한다.
- 라운드 중 기준을 변경하지 않는다.
- 특정 동물만 예외로 만들지 않는다.
- 카드 배치 전에 플레이어 예측이 끝났는지 확인한다.
- 오답 가설에 부분 힌트를 주지 않는다.
- 표정, 시선, 손짓, 망설임을 최소화한다.
- "좋은 카드 골랐네", "거의 맞았어" 같은 말을 하지 않는다.
- 직접 예/아니오 질문에 답하지 않는다.

## 10. 플레이어 주의사항

- 비밀 카테고리 카드나 Decider 메모를 보지 않는다.
- 이미 분류된 카드를 옮기지 않는다.
- 결과를 보기 전에 먼저 예측한다.
- 동물 이름 맞히기가 아니라 두 그룹의 공통점과 차이를 본다.
- 비슷한 카드만 반복하기보다 가설을 구별할 동물을 찾는다.

## 11. 직접 만든 Category 카드

### SOURCE 원본형
`X / X가 아님`

### PROJECT DEFAULT 추가형
- 원본형 빈 카드 4장
- LEFT / RIGHT 자유 작성형 4장

작성 조건:
- 두 범주가 겹치지 않도록 한다.
- 어느 쪽에도 속하지 않는 동물이 생기지 않게 한다.
- 게임 중 수정하지 않는다.
- 지나치게 주관적인 기준은 가급적 피한다.

## 12. 애매한 판정

`Colorful`, `Eats bugs` 등은 해석 차이가 생길 수 있다.

`PROJECT DEFAULT`

1. Decider는 가능하면 라운드 전에 판정을 정한다.
2. 논쟁이 생겨도 비밀 카테고리를 중간에 공개하지 않는다.
3. 해당 라운드에서는 기존 판정을 유지한다.
4. 라운드 후 문제를 기록한다.
5. 반복되면 개선판에서 수정할 후보로 남긴다.

## 13. 라운드 종료

비밀 카테고리 한 쌍을 정확히 맞히면 종료한다.

`PROJECT DEFAULT`
- 의미가 같으면 정답 인정
- 점수 없음
- 다음 Decider는 시계 방향

## 14. 현재 원작판에서 사용하지 않는 것

다음은 AI Detective 개선판에서 다룬다.

- True / False 보드
- Query 토큰
- Feature 아이콘
- wings / legCount / habitat 등의 구조화 Feature
- AND / OR 난이도
- 점수 트랙
- 자동 판정

## 15. 이미지와 카드 제작

현재 원작판 프로토타입:
- 동물 이미지: PLIX 원본 그대로 활용
- 동물 이름: 한국어 적용
- Category Idea: 한국어판 자체 제작
- 직접 작성 Category 카드: 큰 빈칸 확보
- 플레이 영역: LEFT / NEXT / RIGHT 자체 제작

외부 배포/판매 전에는 원본 이미지/카드 디자인 라이선스를 다시 확인한다.

## 16. 현재 검증할 것

- 예시 카드 3장이 적절한가
- 46장 전체 공개가 선택에 도움이 되는가
- NEXT 단계가 예측을 명확하게 만드는가
- 오답 페널티가 없어도 무작정 추측하지 않는가
- `Colorful`, `Eats bugs`에서 판정 분쟁이 얼마나 생기는가
- 플레이어가 정보 가치가 높은 동물을 고르기 시작하는가
- 한 라운드 시간이 교실 수업에 적절한가
